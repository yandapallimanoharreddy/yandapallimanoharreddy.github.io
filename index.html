SmartAuth
AI-driven adaptive authentication
● Live

Replaces static rule-based authentication with a real-time XGBoost ML risk scoring engine built on ForgeRock AM 7.3. Every login scored in milliseconds — low risk allows, medium triggers step-up MFA, high blocks and fires an audit event to ForgeRock IDM 7.

ForgeRock AM 7.3ForgeRock IDM 7PythonXGBoostFastAPIReactJavaScriptForgeRock DS
Architecture
Login→ Collect signals→ Time anomaly→ Failed attempts→ Risk engine caller→ XGBoost model→ Allow / Step-up / Block→ IDM audit
What it does
→4 custom JavaScript scripted decision nodes in ForgeRock AM 7.3 — collects device fingerprint, browser, OS, IP address, login hour and failed attempts on every login
→Python FastAPI microservice running XGBoost classifier trained on 10,000 synthetic login scenarios — returns risk score in under 50ms
→Adaptive auth tree: low risk → passwordless, medium → step-up TOTP MFA, high → block and alert IDM automatically
→Every risk decision automatically audit logged to ForgeRock IDM 7 as a managed object — full governance trail with userId, score, action, timestamp
→Live React dashboard — reads from IDM REST API every 10 seconds, shows risk distribution bar chart, pie chart and colour-coded auth events table

IdentityGuard
Autonomous NHI intelligence
🔨 Building

Autonomous Non-Human Identity intelligence framework on ForgeRock AM/IDM. Discovers every service account, OAuth2 client, API key and AI agent — profiles behaviour, detects anomalies using Isolation Forest ML, explains every decision in plain English via SHAP values, and auto-remediates with zero human intervention.

ForgeRock AM/IDMPythonIsolation ForestSHAPFastAPIReactOAuth2LDAP
The problem
→Every enterprise has 10x more non-human identities than human ones — service accounts, API keys, AI agents — but IAM tools were built for humans
→SolarWinds, Microsoft Exchange, Uber — all major breaches caused by a compromised non-human identity nobody was watching
→SailPoint, Saviynt and CyberArk charge £500k+ for partial NHI governance — no open-source working solution exists
Architecture
NHI discovery→ Behaviour profiler→ Isolation Forest→ SHAP explainability→ Autonomous decision→ IDM remediation→ Live dashboard
What it will do
→4 custom ForgeRock AM scripted nodes — discover, fingerprint and profile every NHI across AM, IDM and DS automatically
→Isolation Forest ML model — learns normal behaviour per NHI and flags deviations in real time without needing labelled attack data
→SHAP values produce plain English explanations: "This service account called 47 new endpoints in 10 minutes — 94% confidence compromised"
→Autonomous IDM remediation — revoke token, rotate credentials, quarantine NHI, alert team — zero human intervention required
→React dashboard — full NHI estate view with risk scores, anomaly timeline, remediation log and explainability panel
